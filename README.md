# Safrochain CW721 NFT Project

Projet Web3 réalisé sur Safrochain Mainnet dans le cadre d'une mission DYMA.

## Objectif

Déployer un smart contract CW721, créer une collection NFT et mint un NFT avec Keplr Wallet.

## Technologies

- Safrochain Mainnet
- CosmWasm / CW721
- JavaScript, HTML et Vite
- CosmJS
- Keplr Wallet
- Ubuntu WSL

## Réalisations

- Déploiement du smart contract CW721 : Code ID 21
- Création de la collection Safrochain Genesis Cube (SGC)
- Mint du NFT genesis-cube-001
- Vérification de la transaction sur l'explorateur Safrochain
